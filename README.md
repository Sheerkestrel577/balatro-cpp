## balatro-cpp
A headless re-implementation of the Balatro game engine in C++20, built so that
reinforcement-learning agents can play millions of runs fast.

## What's implemented:
- All 150 Jokers and all 52 consumables
- Blinds, bosses, shop, packs, vouchers, hand scoring
- Python bindings via ctypes
- Plasma Deck, White Stake

## What's not done
- Still has bugs in some joker interactions
- Other decks/stakes (no plans)
